# Pribadi · Manajemen Seragam (deploy branch)

This branch is generated by GitHub Actions ("Build for cPanel") on every push to `main`. **Do not edit it by hand.** Change the code on `main` instead.

It holds the ready-built app: `dist/` (page and API), the small server in `server/`, and the database migrations in `drizzle/`. It needs Node.js 22.13+ and no npm packages.

To update the live site, run this in cPanel Terminal:

```sh
bash ~/repositories/uniform/update.sh
```

Stock data lives in `~/seragam-data/inventory.sqlite`, outside this folder.
